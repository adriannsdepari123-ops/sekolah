About Me

Tentang Gua

Halo semuanya! Nama gua Adrian Sembiring Depari, biasa dipanggil ADN. Sekarang gua lagi duduk di bangku kelas 9D di SMPN 24 Depok.

Di luar kegiatan sekolah, hobi utama gua adalah main game. Dari kesukaan gua main game itulah, rasa penasaran gua mulai muncul: "Gimana sih cara kerja di balik sebuah game atau website?"

Akhirnya gua mulai iseng-iseng belajar ngoding secara otodidak. Mulai dari bikin script Python sederhana seperti web scraping buat ngambil data otomatis, belajar ngerancang tampilan website kayak yang lagi lu liat sekarang, sampai bikin game interaktif sendiri pakai Scratch. Buat gua, ngoding itu seru karena kita bisa bikin ide di kepala jadi nyata!
